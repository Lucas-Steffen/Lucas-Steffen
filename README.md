## About me

Software Engineer focused on **backend systems, distributed architectures and developer experience**. I like turning messy real-world problems into APIs that are boring to operate and fast to extend.

- Currently building **[Conversy](https://conversy.tech)** — an AI platform that helps entrepreneurs sell more.
- Day to day: **TypeScript**, **NestJS**, **PostgreSQL**, **Redis**, **Docker**, observability with **Grafana + Prometheus**.
- Interested in event-driven design, queue processing, caching strategies and clean domain modeling.
- Open to collaborating on open-source backend tooling and AI-powered products.
